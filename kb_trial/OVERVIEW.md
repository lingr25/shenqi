# 唯一试验版本总览

本次使用入口为根目录 `kb_trial_search.py`，产物统一在 `kb_trial/`。状态为 **本地试验 draft**；不是权威知识库，也未达到开源就绪。历史 `kb_pilot_synth/` 保留为只读来源，不再新增 round。没有 API 调用、全量 LLM 重跑、依赖安装、提交或发布。

## 构建与文件

在仓库根目录执行：

```bash
python kb_build_trial.py
python kb_trial_search.py --self-test
python kb_trial_search.py "事件帧目标丢失重新抬手"
python kb_trial_search.py "小莫施怀雅镜像力径向力" --mode experiment
python kb_trial_search.py "维尼斯推海默向上刹车" --json
python kb_trial_search.py "夜半眠兽撤退睡眠解除" --mode all --track qq --entity 夜半
python kb_trial_search.py "穿刺花生命比例相同时看仇恨吗" --mode all
python kb_trial_search.py --id "fc1:其他-8-8"
python kb_trial_search.py --evidence "BV1qReG6XE6W_p1_41897493495:p22:a7:e7cd81f8"
python kb_eval.py
```

命令行用双引号包住中文查询和带 `#` 的 ID。Python 标准库及现有 `kb_search.BM25` 足够；路径相对脚本定位。没有回答生成器：输出的是带完整正文、证据 ID、来源与审核状态的检索结果。

| 文件 | 用途 |
|---|---|
| `docs.jsonl` | 机制和实验检索记录 |
| `archive.jsonl` | 待核与拒绝/撤回记录，均有明确 mode |
| `evidence.jsonl` | 原子引用及原始引文、时间戳窗口，保持原字 |
| `overlay.jsonl` | 用户反馈落到旧表示隔离与派生文本纠错的操作记录 |
| `entity_index.json` | 保留既有实体/别名索引，追加用户纠错别名及类型 |
| `manifest.json` | 来源 SHA-256、脚本 SHA-256、产物 SHA-256、实际分类计数 |
| `validation.json` | 幂等、源 hash、引文、边界、逐题检索与盲测明细 |
| `OVERVIEW.md` | 本报告 |

构建器输入为审核后 1,337 卡、反馈归档 2 卡、gate v2 归档 1,091 行、旧保留 21,801 行，另保留既有 85 张独立证据/实验卡；生产 `kb/docs.jsonl` 只读用于证据解析，实体索引只读复制。重建不依赖历史 API 客户端。

输出排序固定，不含运行时间字段；连续构建两次 manifest 和五份数据输出的字节 hash 相同。manifest 登记了使用的原字幕/ASR 文件 hash，来源逐项重验不变。生产 `kb/docs.jsonl` 的 SHA-256 为 `b835a8bfec6a7bb3c4b451d547a73ffc3fee165635e759a466837c99cfe08897`，`kb/synthesized.jsonl` 为 `373554a096daba7cb30ecb0407c54313f02849f9c40c5a6fb93dd9fc103c2e36`，均未覆盖。

## 实际规模与模式

计数单位是检索记录，包含拆分的实例/待核章节，不等于独立机制数量。合计 **26,064** 条：`docs.jsonl` **13,316**，`archive.jsonl` **12,748**。

| 模式 | 条数 | 使用规则 |
|---|---:|---|
| mechanism | 2,729 | 默认；机制候选草稿，仍不等于已证实真值 |
| experiment | 10,587 | 显式 `--mode experiment`；单次实验、实例，不外推 |
| pending | 12,638 | 显式 `--mode pending`；待核，不得当已知 |
| archive | 110 | 仅显式 `--mode archive` 或 `--id` 查原文，不能作为现行结论 |
| all | 25,954 | 合并前三种模式，各条保留警告；排除拒绝/撤回原文 |

待核数较大是本次保守隔离的真实代价：旧条目与已归档簇或待核证据精确关联时进入待核，未把同簇相似度当语义覆盖证明。没有批删来源；含多命题的旧记录可能被整条隔离，未隔离的派生规则仍可从 fc1 检索。这个选择压低默认模式召回率，见评测。

## 引用和限制

引用索引共 **16,069** 个：原子 ID 解析 **13,226**，时间戳窗口 **2,842**，未解析 **1**。未解析项 `BV1dVcbzFEdd_p2_35992767409:p14:a0:17f19616` 保留 unresolved，关联记录进入 pending。原子解析仅表示能定位既有引用对象；并未逐条核听，也未证明原子引文与音频一致。时间戳窗口使用请求秒之前最近字幕行，最多差 120 秒，保留请求秒及原行，不能等同精确命题支持。

其他限制：

- 分层依赖历史标签和确定性保守规则；部分机制候选仍可能是非机制内容，未做全库语义重审。
- 待核旧记录与新卡仍可能重复，本次不以相似度或同簇关系作为可删除证明。
- 来源类型为 unknown 的记录如实保留；不因缺来源自动宣称官方。
- 没有重新生成历史 30 题 LLM 回答，历史报告的答案分数不属于本版测试；原有 N09 欠断定、N15 上下文截断等问题未在本地检索任务中宣称解决。
- 文本纠错只在明确来源范围内传播；范围之外需要新的证据或用户审核。
- entity_index 保留旧索引，追加类型和别名；未全面重建上游实体词库。
